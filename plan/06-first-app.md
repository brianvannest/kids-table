# Phase 6: your first app on your own computer

Read `plan/00-app-plan.md` first. It says what the whole app is. This phase builds only the starting shell, so you can see something running.

## Goal

A new Next.js app, in this folder, running on your own computer at a local address. It shows a simple placeholder home page for The Kids' Table.

## What to build

- A Next.js app using the App Router and TypeScript, with Tailwind CSS and ESLint.
- A home page that says "The Kids' Table" and "A small fry guide", and nothing else yet.
- A clean first commit on `main`, ready to push to GitHub in the next phase.

## Rules for this phase

- Work only in this folder.
- Do not add a database, sign-in, or any secrets yet.
- Explain each command before you run it, in plain English.
- Keep the code simple enough that a beginner can read it.

## Done when

- `npm run dev` starts without errors.
- Opening the local address shows the home page.
- `npm run lint` and `npm run build` both pass.
- The files are committed, with a short message that says what they are.

## Out of scope

The public page, sign-in, the database, photos, and deploying. Those are later phases.
